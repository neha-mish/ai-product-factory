# Product Artifacts

This directory holds durable artifacts for individual product concepts after exploratory work has earned promotion from a run.

A human reviewer promotes an artifact only when it is useful as a current source of truth, its assumptions and unknowns remain explicit, and its provenance links to the originating run. Promotion does not imply product approval or production readiness.

Product-specific learning stays here. Only synthesized knowledge that applies across concepts should be promoted onward to the [`knowledge/wiki`](../knowledge/wiki/index.md).
