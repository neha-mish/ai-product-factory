# Run Artifacts

This directory holds execution-specific inputs, sourced evidence, intermediate artifacts, approvals, and outputs. Each future run should have a distinct directory and retain enough provenance to explain its conclusions.

Raw run output remains here. A human may promote a reviewed, stable product artifact to [`products/`](../products/README.md); reusable cross-product learning may reach the [`knowledge/wiki`](../knowledge/wiki/index.md) only after synthesis and review.

Chat history is not the record. Material inputs, gate decisions, and specialist outputs belong in Markdown run artifacts.
