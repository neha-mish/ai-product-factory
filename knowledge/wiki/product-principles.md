# Product Principles

1. Humans define intent, constraints, acceptance criteria, and approval.
2. Agents perform bounded specialist work with explicit responsibilities.
3. Frame the problem before selecting a solution.
4. Preserve assumptions and unknowns; never invent evidence.
5. Design evaluation before implementation.
6. Separate builder and evaluator concerns where practical.
7. Use AI only where it creates material value; prefer deterministic software otherwise.
8. Keep important knowledge in reviewed Markdown artifacts rather than chat history.
9. Make consequential transitions explicit through human gates.
10. Ensure public portfolio experiences can run without paid model calls or API keys.

These are governing principles, not claims of validated product outcomes. Revisit them when evidence from multiple product runs reveals a recurring conflict or omission.
